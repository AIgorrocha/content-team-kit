# 8 Prompts Essenciais para Design com IA

Prompts especializados para gerar design systems, identidade visual, UI/UX, assets de marketing e mais.
Usar como referencia quando os agentes precisarem criar materiais visuais avancados.

---

## PROMPT 1: Design System Architect

Cria design system completo: paleta de cores, tipografia em 9 niveis, grid 12 colunas, espacamento 8px, 30+ componentes com estados, tokens JSON e guia para devs.

```
Act as Apple Principal Designer. Build a complete design system for [BRAND]. Include foundations: color system (primary, semantic, dark mode, contrast, usage), typography (9 levels, responsive scale, accessibility), 12-column grid, 8px spacing. Design 30+ components with states, anatomy, usage, accessibility, and code specs. Add patterns, design tokens JSON, principles, do's/don'ts, and dev guide. Publish-ready.
```

**Quando usar:** Quando o cliente precisa de um design system do zero ou quer profissionalizar sua identidade visual.

---

## PROMPT 2: Brand Identity Creator

Cria identidade de marca completa: estrategia, arquetipos, 3 direcoes de logo, sistema de cores com Hex/Pantone/CMYK, tipografia, estilo visual e estrutura de brand book com 20 paginas.

```
Act as Creative Director at Pentagram. Build a complete brand identity for [COMPANY], a [INDUSTRY] brand targeting [AUDIENCE]. Include: brand strategy (story, archetype, voice matrix, messaging hierarchy), 3 logo directions + variations + usage rules, full color system (Hex, Pantone, CMYK, RGB + rationale), typography, imagery style, brand applications, and a 20-page brand book structure. Explain strategy behind every decision.
```

**Quando usar:** Clientes novos sem identidade visual definida, ou rebranding.

---

## PROMPT 3: UI/UX Pattern Master

Projeta interfaces completas com 8 telas principais, wireframes, componentes, estados vazios/erro/carregamento, gestos, acessibilidade WCAG e microinteracoes.

```
Act as a Senior Apple UI Designer. Design a full UI for [APP TYPE] based on [PERSONA], goals, and pain points. Follow Apple HIG. Define hierarchy, layout patterns, navigation, gestures, and platform rules. Detail 8 core screens with wireframes, components, interactions, empty/error/loading states. Specify buttons, forms, cards, data viz, accessibility (WCAG, VoiceOver, Dynamic Type), micro-interactions, and responsive behavior. Include Designer's Notes.
```

**Quando usar:** Quando o agente Designer precisa criar interfaces ou dashboards.

---

## PROMPT 4: Marketing Asset Factory

Gera toda a biblioteca de materiais de campanha: Google Ads, Meta/TikTok, sequencias de email, landing page, posts, pecas de vendas, com copy, direcao visual e testes A/B.

```
Act as Creative Director at a top agency. Build a full campaign asset library for [PRODUCT]. Include: Google Ads, Meta/TikTok ads, email sequences (welcome, promo, nurture, re-engagement), landing page copy, social posts, sales enablement materials, and content marketing outlines. Provide exact copy, visual direction, CTA, and A/B tests for each. Maintain consistent messaging, tone, and hierarchy across all assets.
```

**Quando usar:** Campanhas grandes, lancamentos de produto, material de vendas.

---

## PROMPT 5: Figma Auto-Layout Expert

Converte descricao de design em specs prontas pra Figma: frames, grids, constraints, auto-layout, arquitetura de componentes, tokens, fluxos de prototipo e handoff pra dev.

```
Act as a Figma Design Ops Specialist. Convert [DESIGN DESCRIPTION] into Figma-ready specs. Define frame structure, grids, constraints, and responsive rules. Detail auto-layout (direction, padding, spacing, alignment, resizing). Build component architecture with variants and properties. Include design tokens (colors, text, effects), prototype flows with triggers and animations, dev handoff setup (CSS, exports, naming), and accessibility notes.
```

**Quando usar:** Quando precisar criar specs de Figma a partir de um briefing ou converter design em implementacao.

---

## PROMPT 6: Design Critique Partner

Critica qualquer design usando 10 heuristicas de Nielsen (notas 1-5), hierarquia visual, tipografia, cor, usabilidade, acessibilidade e alinhamento estrategico. Entrega prioridades e 2 direcoes alternativas.

```
Act as an Apple Design Director. Critique [DESIGN]. Evaluate via Nielsen's 10 heuristics (score 1-5 with examples), visual hierarchy, typography, color, usability, and strategic alignment. Identify cognitive load, accessibility (WCAG), interaction clarity, and differentiation. Provide prioritized fixes (Critical, Important, Polish). Propose 2 alternative redesign directions described clearly. Tone: constructive, actionable, educational.
```

**Quando usar:** Revisar carrosseis, posts, ou qualquer material visual antes de publicar.

---

## PROMPT 7: Design Trend Synthesizer

Analisa tendencias de design do ano em qualquer setor: 5 macrotendencias, mapa 2x2 de concorrentes, mudancas de expectativas, evolucao de plataformas, roadmap de 6 meses e mood board.

```
Act as a frog Design Researcher. Analyze 2026 trends for [INDUSTRY]. Deliver: 5 macro trends (definition, visuals, origin, adoption phase, 3 brand examples, risks/opportunities), competitor 2x2 map with white space insights, user expectation shifts, platform evolution (iOS, Material, Web), strategic recommendations, 6-month roadmap, and detailed mood board specs with palette + typography guidance. Be specific and cite real brands.
```

**Quando usar:** Pesquisa de tendencias visuais, planejamento de identidade visual, analise competitiva de design.

---

## PROMPT 8: Design-to-Code Translator

Converte qualquer design em codigo frontend pronto pra producao: hierarquia de componentes, props, estados, ARIA, animacoes, CSS/Tailwind com tokens, dark mode, breakpoints e documentacao.

```
Act as a Vercel Design Engineer. Convert [DESIGN] into production-ready frontend code using [TECH STACK]. Deliver component hierarchy, props, states, ARIA, animations, CSS/Tailwind with tokens, dark mode, breakpoints, asset optimization, and documentation.
```

**Quando usar:** Quando o agente Carrossel ou Designer precisa converter um design em HTML/CSS funcional.
