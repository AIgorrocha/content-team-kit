# Documentação

Comece pelo `README.md` da raiz (uso do dia a dia) e por `SETUP.md` (instalação).

## Instalação e conexões

| Arquivo | Para que serve |
|---|---|
| `SETUP.md` | Instalação completa numa máquina nova |
| `INTEGRACOES.md` | Cada integração, chave por chave (todas opcionais) |
| `CONECTAR-REDES.md` | Conectar as redes pelo painel |
| `CHECAGEM-CONEXOES.md` | Conferir se as conexões ainda valem |
| `SALA-TERMINAL.md` | Ligar o terminal ao quadro Trabalho do painel |
| `COMO-RECEBER-ATUALIZACOES.md` | Baixar o kit, guardar a marca num repositório privado, atualizar e reportar problema |
| `SKILLS-EXTERNAS.md` | Ferramentas de terceiros recomendadas (opcionais) e como avaliar uma nova |

| Arquivo | Para que serve |
|---|---|
| `APRENDIZADO-DIARIO.md` | O time aprende todo dia com o seu Instagram (o que funciona, linguagem, ganchos) e, com travas, atualiza as regras da marca |
| `LOOP-DE-APRENDIZADO.md` | Como cada correção vira regra permanente da marca |
| `FLUXO-YOUTUBE-PARA-REDES.md` | Um vídeo longo vira várias peças, uma por rede |
| `FLUXO_SINCRONIZACAO.md` | Como agentes e skills sobem para o banco do painel |
| `PUBLICACAO_AUTO.md` | Publicação automática agendada no Instagram |
| `ICLOUD-INBOX.md` | Mandar foto e vídeo do celular direto para o time |
